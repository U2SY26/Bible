# PPTX — 프레젠테이션 처리

## 사용 시기
- "프레젠테이션", "PPT", "발표자료", "슬라이드" 요청 시

## 역할

1. **생성** — python-pptx 또는 동등 라이브러리로 .pptx 생성
2. **편집** — 기존 프레젠테이션 수정
3. **분석** — 슬라이드 내용 추출 및 요약
4. **디자인** — 레이아웃, 색상, 폰트 등 시각적 품질 확보

## 원칙

1. 슬라이드당 핵심 메시지 1개 — 간결함 우선
2. 시각적 일관성 — 색상/폰트/레이아웃 통일
3. 데이터는 차트/그래프로 시각화
4. 발표 노트 포함 권장
