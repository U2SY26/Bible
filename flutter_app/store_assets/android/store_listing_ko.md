# Google Play Store 등록 정보 (한국어)

## 앱 이름
그래프 성경

## 간단한 설명 (80자 이내)
성경 인물들의 관계를 시각적 그래프로 탐험하세요. 600+ 인물, 350+ 관계, 타임라인 포함.

## 자세한 설명 (4000자 이내)
📖 그래프 성경은 성경 속 인물들의 관계를 인터랙티브한 그래프로 시각화하여 성경을 새로운 방식으로 이해할 수 있게 도와주는 앱입니다.

✨ 주요 기능:

🔗 인물 관계 그래프
• 600명 이상의 성경 인물 데이터
• 350개 이상의 관계 (가족, 영적 관계, 갈등 등)
• 드래그로 노드를 이동하며 탐색
• 핀치 줌으로 확대/축소
• 인물 선택 시 관련 관계 하이라이트

📅 타임라인
• 시대별 주요 사건 정리
• 창조 시대부터 초대교회까지
• 인물과 사건의 시간적 맥락 이해

📚 성경 읽기
• 개역개정 성경 전문 66권
• 구약 39권, 신약 27권
• 장/절 단위 탐색
• 깔끔한 다크 테마 UI

🔍 검색 기능
• 인물 이름, 역할, 설명으로 검색
• 빠른 필터 (선지자, 왕, 제자 등)
• 검색 결과에서 바로 인물 정보 확인

🌐 이중 언어 지원
• 한국어 / 영어 전환 가능
• 모든 인물 정보 양국어 제공

💡 그래프 성경을 추천하는 대상:
• 성경을 체계적으로 공부하고 싶은 분
• 성경 인물들의 관계가 궁금한 분
• 성경 타임라인을 이해하고 싶은 분
• 새로운 방식으로 성경을 탐험하고 싶은 분

📱 특징:
• 오프라인 사용 가능 (인터넷 불필요)
• 어두운 테마로 눈의 피로 감소
• 직관적인 터치 인터페이스
• 빠른 앱 시작

성경의 세계를 그래프로 탐험해 보세요!
