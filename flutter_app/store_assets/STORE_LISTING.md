## 앱 설명

### 한국어 (Korean)

**짧은 설명 (80자)**
```
600명 이상의 성경 인물을 인터랙티브 그래프로 탐험하세요. 관계, 사건, 타임라인을 시각화합니다.
```

**긴 설명**
```
그래프 성경은 성경 속 인물들의 관계를 아름다운 인터랙티브 그래프로 시각화합니다.

주요 기능:
• 600명 이상의 성경 인물 데이터
• 350개 이상의 인물 관계 (가족, 영적 멘토, 갈등 등)
• 100개 이상의 성경 사건 타임라인
• 66권 성경 전문 (개역개정)
• MBTI 성격 유형 퀴즈로 나와 비슷한 성경 인물 찾기
• 한국어/영어 이중 언어 지원
• 다크 모드 & 라이트 모드
• 텍스트 크기 조절 (접근성)
• 즐겨찾기 기능으로 관심 인물 저장

성경을 더 깊이 이해하고 싶은 분들께 추천합니다.
구약과 신약의 인물들이 어떻게 연결되어 있는지 한눈에 파악하세요.

무료로 사용 가능하며 광고가 포함되어 있습니다.
```

### English

**Short Description (80 chars)**
```
Explore 600+ Bible characters in an interactive graph. Visualize relationships, events & timeline.
```

**Long Description**
```
Graph Bible visualizes relationships between Bible characters in a beautiful interactive graph.

Key Features:
• 600+ Bible character profiles
• 350+ character relationships (family, spiritual mentors, conflicts, etc.)
• 100+ Bible events timeline
• Complete 66 books of the Bible
• MBTI personality quiz to find your Bible character match
• Bilingual support (Korean/English)
• Dark mode & Light mode
• Adjustable text size (accessibility)
• Bookmark feature to save favorite characters

Perfect for anyone wanting to understand the Bible more deeply.
See how Old and New Testament characters are connected at a glance.

Free to use with ads included.
```

### 권장 스크린샷 구성

1. **메인 그래프 화면** - 인물 관계 그래프 표시
2. **인물 상세 정보** - 바텀시트로 인물 정보 표시
3. **타임라인 화면** - 시대별 사건/인물
4. **성경 리더** - 성경 읽기 화면
5. **MBTI 퀴즈** - 퀴즈 또는 결과 화면
6. **검색 화면** - 인물 검색 기능
7. **설정 화면** - 테마/언어 설정
8. **즐겨찾기** - 북마크된 인물 목록
