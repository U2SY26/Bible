## 🚀 출시 단계

1. **Google Play Console 접속**
   - https://play.google.com/console

2. **새 앱 만들기**
   - 앱 이름: 그래프 성경
   - 기본 언어: 한국어
   - 앱/게임: 앱
   - 무료/유료: 무료

3. **스토어 등록정보 설정**
   - 앱 세부정보 입력
   - 그래픽 자료 업로드
   - 카테고리 선택

4. **앱 콘텐츠 설정**
   - 개인정보처리방침 URL
   - 광고 포함 여부
   - 콘텐츠 등급 설문
   - 타겟층 설정

5. **AAB 업로드**
   - 프로덕션 트랙에 AAB 업로드
   - 또는 내부 테스트 트랙으로 먼저 테스트

6. **검토 요청**
   - 모든 필수 항목 완료 후 검토 제출
   - 검토 기간: 보통 1-7일
